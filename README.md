# Library Management System

## Introduction

The Library Management System is a console-based C++ application designed to manage books, members, and borrowing records.

The system uses Object-Oriented Programming and file handling.

## Features

- Add books
- Display books
- Add members
- Display members
- Issue books
- Return books
- Search books by title
- Search books by author
- Store records using file handling
- Menu-driven interface

## Technologies Used

- C++
- Object-Oriented Programming
- File Handling
- Standard C++ Library

## Book Information

The system stores:

- Book ID
- Book Title
- Author
- Book Status

## Member Information

The system stores:

- Member ID
- Member Name

## Library Operations

### Add Book
Adds a new book to the library.

### Add Member
Adds a new library member.

### Issue Book
Issues an available book to a registered member.

### Return Book
Returns an issued book and makes it available again.

### Search Book
Books can be searched by title or author.

## File Handling

Book records are stored in `books.txt`.

Member records are stored in `members.txt`.

The files are automatically created when the program is run in an environment that permits file writing.

## Expected Outcome

A functional Library Management System that enables book addition, member management, book issue and return processing, and searching by title or author.
